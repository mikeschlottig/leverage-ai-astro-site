Trafilatura is a**Python package and command-line tool**designed to gather text on the Web and simplify the process of turning raw HTML into structured, meaningful data. It performs**web crawling, downloads, scraping, and extraction**of main texts, metadata, and comments from web pages.

The tool is widely used by companies like HuggingFace, IBM, and Microsoft Research, as well as academic institutions including the Allen Institute, Stanford, and the University of Munich. It is integrated into thousands of projects and consistently outperforms other open-source libraries in text extraction benchmarks.

Sources:[README.md](https://github.com/adbar/trafilatura/blob/ee1865b2/README.md?plain=1)[docs/index.rst1-46](https://github.com/adbar/trafilatura/blob/ee1865b2/docs/index.rst#L1-L46)[trafilatura/\_\_init\_\_.py1-10](https://github.com/adbar/trafilatura/blob/ee1865b2/trafilatura/__init__.py#L1-L10)

## What Trafilatura Does

Trafilatura focuses on extracting the**essential content**from web pages while removing**noise**caused by recurring elements like navigation bars, headers, footers, and advertisements. It provides:

*   **Text extraction**: Main content, comments, and metadata (title, author, date, etc.)
*   **URL discovery**: Through sitemaps, feeds, and focused web crawling
*   **Multiple output formats**: TXT, XML, JSON, CSV, HTML, Markdown, and XML-TEI
*   **Robust processing**: Fallback algorithms and configurable extraction strategies
*   **Parallel processing**: Efficient handling of large-scale downloads

The extractor strikes a balance between precision (limiting noise) and recall (including all valid parts), making it suitable for various text collection tasks including corpus building, data mining, and content analysis.

Trafilatura's architecture consists of six major functional layers:

1.  **User Interfaces**: Three primary interfaces - CLI (`trafilatura`command), Python API (`extract()`,`fetch_url()`), and R interface via reticulate
2.  **Core Processing Engine**: The extraction engine in[core.py](https://github.com/adbar/trafilatura/blob/ee1865b2/core.py)orchestrates HTML processing, metadata extraction, and fallback mechanisms
3.  **Content Discovery**: Three strategies for URL discovery - sitemaps ([sitemaps.py](https://github.com/adbar/trafilatura/blob/ee1865b2/sitemaps.py)), feeds ([feeds.py](https://github.com/adbar/trafilatura/blob/ee1865b2/feeds.py)), and focused crawling ([spider.py](https://github.com/adbar/trafilatura/blob/ee1865b2/spider.py))
4.  **Download Management**: Handles HTTP requests with politeness rules and URL filtering via the courlan library
5.  **Data Quality**: Ensures clean output through deduplication (SimHash-based) and filtering
6.  **Output & Storage**: Converts extracted content to multiple formats (TXT, XML, JSON, CSV, HTML, Markdown, XML-TEI)

This pipeline shows the complete data flow from input to output:

1.  **Input Sources**: URLs, lists, sitemaps, feeds, crawling results, or local HTML files
2.  **URL Management**: Filtering, cleaning, and deduplication via the courlan library's`UrlStore`
3.  **Acquisition**: Downloads with politeness rules (`robots.txt`, rate limiting) and Internet Archive fallback
4.  **Extraction Pipeline**: HTML parsing (`load_html()`), metadata extraction (`extract_metadata()`), cleaning (`tree_cleaning()`), and content extraction (`extract_content()`)
5.  **Quality Control**: Language filtering, size validation, and SimHash-based deduplication
6.  **Output Processing**: Multiple formats via`build_xml_output()`,`build_json_output()`,`xmltotxt()`
7.  **Storage**: Files or standard output

## Installation and Usage

### Installation

Trafilatura is available from PyPI and can be installed with pip:

```
pipinstalltrafilatura
```

For additional functionality (language detection, speed optimizations):

```
pipinstalltrafilatura[all]
```

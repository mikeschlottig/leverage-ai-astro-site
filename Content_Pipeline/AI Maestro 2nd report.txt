                    <div class="section-banner">Section 1 — Executive Summary</div>
                    
                    <p class="lead">AI Maestro is a free, open-source, MIT-licensed orchestration platform for AI coding agents, built by Juan Peláez and the 23blocks team in Boulder, Colorado.                 <div class="content-card">
                    <div class="section-banner">Section 2 — Project Philosophy & Origin</div>
                    
                    <p>AI Maestro was not designed in a vacuum. The creator, Juan Peláez, describes each feature as born from a real problem encountered while running agents at scale: <em>"35 terminals and couldn't tell which was which."</em> The project philosophy is grounded in three tenets:</p>

                    <h2>2.1 Radical Local-First Ownership</h2>
                    <p>Every byte of data — agent notes, memory, conversation history, code graphs — lives on the operator's machines. There are no Anthropic/23blocks servers in the data path. The platform explicitly states: <em>"We don't have servers, we don't collect data, we don't phone home. Your code stays yours."</em> This is architecturally enforced, not just a policy claim.</p>

                    <h2>2.2 Peer Mesh Over Master/Slave</h2>
                    <p>The multi-machine architecture is explicitly described as <em>"peer mesh with no central server — nobody else does this."</em> Every node in the mesh is equal; there is no designated orchestrator node that becomes a single point of failure. Dashboard connectivity to remote peers is implemented through SSH-tunneled WebSocket connections, meaning any machine can become the 'control node' by opening the browser on it.</p>

                    <h2>2.3 Agent Communication as First-Class Primitive</h2>
                    <p>The Agent Messaging Protocol (AMP), maintained by 23blocks under the Apache 2.0 license at agentmessaging.org, gives each agent a persistent inbox with four priority levels and four message types. Agents coordinate on deliverables without the human developer acting as a relay. The creator puts it plainly: <em>"Talking isn't working. I needed agents to coordinate on actual deliverables."</em></p>
                </div>
            </div>

                    <h2>3.2 Process Topology</h2>
                    <p>On a single machine, AI Maestro runs as a Next.js server process. It communicates with the local tmux server via the tmux command-line interface (not a daemon). The remote peer must have AI Maestro installed and running. Sessions on the remote host appear in the primary dashboard with a hostname prefix.</p>

                    <h2>3.4 Agent Subconscious Process</h2>
                    <p>A background process called the 'Agent Subconscious' runs per agent, maintaining memory automatically. Its activity-based scheduling:</p>
                    <ul>

                        <li><strong>Idle:</strong> Memory check every 30 minutes, consolidation every 60 minutes</li>
                        <li><strong>Disconnected:</strong> Memory check every 60 minutes, consolidation every 120 minutes</li>

                        <li>Delta — 1 file changed: ~130ms</li>

                    <h2>6.1 Threat Model</h2>
                    <p>AI Maestro operates entirely within the operator's infrastructure. Primary threat vectors:</p>
                    <ul>
                        <li>Prompt injection via external messages (Slack, email, CI/CD webhooks)</li>
                        <li>Unauthorized access to the dashboard WebSocket endpoint</li>
                        <li>Agent identity spoofing in the AMP message system</li>
                    </ul>

                    <h2>6.2 Content Security Layer</h2>
                    <p>Messages from external sources are wrapped in &lt;external-content&gt; tags. A 34-pattern scanner detects:</p>
                    <ul>
                        <li>Instruction override attempts ('ignore all previous instructions')</li>
                        <li>System prompt extraction attempts</li>
                        <li>Command injection (curl/wget, rm -rf, sudo, eval/exec)</li>
                        <li>Data exfiltration attempts (base64 encoding tricks)</li>
                        <li>Role manipulation / jailbreak patterns (DAN-style prompts)</li>
                    </ul>
                    <p>Agents see trust indicators: ✅ verified AI Maestro agent vs. 🌐 external/unverified vs. ⚠️ suspicious patterns detected.</p>
                </div>

                <div class="content-card">
                    <h2>6.3 Network Security</h2>
                    <p>For multi-machine setups, Tailscale (WireGuard-based) is the recommended VPN:</p>
                    <ul>
                        <li>Zero port forwarding required</li>
                        <li>All traffic encrypted via WireGuard (AES-GCM)</li>
                        <li>Stable Tailscale IPs (100.x.x.x range)</li>
                        <li>Works behind NAT, corporate firewalls, and cellular networks</li>
                    </ul>

                    <div class="callout">
                        <div class="callout-label">Security Warning</div>
                        <p>Do not set HOSTNAME=0.0.0.0 on untrusted networks. Only use network-accessible mode behind a Tailscale VPN or other trusted network boundary.</p>

                <div class="content-card">
                    <div class="section-banner">Section 8 — Known Limitations</div>

                    <h2>8.1 tmux Dependency</h2>
                    <p>AI Maestro is architecturally coupled to tmux. Agents can only be terminal processes inside tmux sessions, and tmux sessions are not persistent across WSL2/OS restarts without additional tooling.</p>

                    <h2>8.2 Alternate Screen Buffer Scrollback</h2>
                    <p>Claude Code uses tmux's alternate screen buffer, preventing traditional scrollback. Scrollback only works in tmux copy mode or with mouse mode enabled. This is a fundamental tmux design limitation.</p>

                    <h2>8.3 Peer Connection Authentication</h2>
                    <p>Peer authentication is via SSH key only. There is no OAuth/token-based authentication for peer connections. Team setups require sharing SSH public keys.</p>

                    <h2>8.4 Windows-Native Support</h2>
                    <p>AI Maestro does not run natively on Windows — it requires WSL2. This introduces VM boundary issues: tmux sessions lost on restart, WSL2 IP changes (mitigated by Tailscale), and no integration with Windows-native agent tools.</p>

                    <h2>8.5 Single-Model Assumption</h2>
                    <p>The Skills system currently assumes Claude Code as the primary agent, though the Agent Skills Standard is designed to be model-agnostic.</p>

                    <h2>8.6 Dashboard Authentication</h2>
                    <p>The AI Maestro dashboard has no built-in user authentication. If bound to 0.0.0.0, anyone who can reach port 23000 has full terminal access. Security relies entirely on network-level protection.</p>

        <button class="page-btn" id="prevBtn" onclick="changePage(-1)">←</button>
        <div class="page-indicators" id="pageIndicators"></div>
        <button class="page-btn" id="nextBtn" onclick="changePage(1)">→</button>

    <script>
        let currentPage = 0;
        const totalPages = 11;
        const wrapper = document.getElementById('pagesWrapper');
        const indicatorsContainer = document.getElementById('pageIndicators');

        // Initialize indicators
        for (let i = 0; i < totalPages; i++) {
            const dot = document.createElement('div');
            dot.className = 'page-dot' + (i === 0 ? ' active' : '');
            dot.onclick = () => goToPage(i);
            indicatorsContainer.appendChild(dot);
        }

        function updateUI() {
            // Update wrapper position
            wrapper.style.transform = `translateX(-${currentPage * 100}%)`;
            
            // Update buttons
            document.getElementById('prevBtn').disabled = currentPage === 0;
            document.getElementById('nextBtn').disabled = currentPage === totalPages - 1;
            
            // Update indicators
            document.querySelectorAll('.page-dot').forEach((dot, index) => {
                dot.classList.toggle('active', index === currentPage);
            });
            
            // Update page counter
            document.getElementById('currentPage').textContent = currentPage + 1;
            
            // Update URL hash for deep linking
            window.location.hash = `page-${currentPage + 1}`;
        }

        function changePage(direction) {
            const newPage = currentPage + direction;
            if (newPage >= 0 && newPage < totalPages) {
                currentPage = newPage;
                updateUI();
            }
        }

        function goToPage(page) {
            if (page >= 0 && page < totalPages) {
                currentPage = page;
                updateUI();
                closeMenu();
            }
        }

        function toggleMenu() {
            const hamburger = document.querySelector('.hamburger');
            const overlay = document.getElementById('navOverlay');
            hamburger.classList.toggle('active');
            overlay.classList.toggle('active');
        }

        function closeMenu() {
            const hamburger = document.querySelector('.hamburger');
            const overlay = document.getElementById('navOverlay');
            hamburger.classList.remove('active');
            overlay.classList.remove('active');
        }

        function closeMenuOnClick(event) {
            if (event.target === document.getElementById('navOverlay')) {
                closeMenu();
            }
        }

        // Keyboard navigation
        document.addEventListener('keydown', (e) => {
            if (e.key === 'ArrowLeft') changePage(-1);
            if (e.key === 'ArrowRight') changePage(1);
            if (e.key === 'Escape') closeMenu();
        });

        // Check URL hash on load
        window.addEventListener('load', () => {
            const hash = window.location.hash;
            if (hash) {
                const pageMatch = hash.match(/page-(\d+)/);
                if (pageMatch) {
                    const page = parseInt(pageMatch[1]) - 1;
                    if (page >= 0 && page < totalPages) {
                        currentPage = page;
                        updateUI();
                    }
                }
            }
        });

        // Touch swipe support
        let touchStartX = 0;
        let touchEndX = 0;

        wrapper.addEventListener('touchstart', (e) => {
            touchStartX = e.changedTouches[0].screenX;
        });

        wrapper.addEventListener('touchend', (e) => {
            touchEndX = e.changedTouches[0].screenX;
            handleSwipe();
        });

        function handleSwipe() {
            if (touchEndX < touchStartX - 50) changePage(1);
            if (touchEndX > touchStartX + 50) changePage(-1);
        }

        // Initial UI update
        updateUI();
    </script>

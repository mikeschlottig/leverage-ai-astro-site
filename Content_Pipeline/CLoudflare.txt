Root cause — Chrome Extension Isolated World boundary:

Chrome content scripts run in an Isolated World — a separate JavaScript context from the page's Main World. Both worlds share the same DOM, but each has its own copy of window, navigator, and all Web APIs.

When the content script does:

js
navigator.clipboard.writeText = function(text) { captured.push(text); }
It's patching clipboard in the Isolated World. When Claude's React copy button is clicked, it calls navigator.clipboard.writeText in the Main World — a completely different object. The patch is invisible to it. Zero captures. Empty content. Every time.

The correct fix: Throw out clipboard interception entirely. Extract content directly from the DOM using a recursive nodeToMarkdown walker. Content scripts have full DOM access across both worlds — that's the shared layer.

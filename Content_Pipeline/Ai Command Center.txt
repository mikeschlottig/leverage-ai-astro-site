What's in the dashboard:
Pluggable Backend Schema — 8 TypeScript interfaces covering ProviderConfig, ProviderAdapter, ModelDefinition, AgentConfig, ChatMessage, MultiAgentSession, RoutingStrategy, and Env bindings for Cloudflare Workers. The ProviderAdapter interface is the key abstraction — add a new provider without touching core agent logic.
Multi-Agent Arena — Anthropic always works via the artifact API. Enable OpenRouter/Requesty/Tetrate by pasting your API key in the sidebar (auto-enables on key entry). Send one prompt → all active providers fire in parallel → responses land in side-by-side cards with latency + token counts.
4 Agent Personas — Data Analyst, CTO Advisor, Creative Director, Default. Each sends a different system prompt to all providers.
Model Catalog — All providers, all models with context windows + pricing.
Integrations tab — Node.js/Python/cURL/advanced snippets for each provider, all copyable.
The RoutingStrategy type supports traffic_split (Tetrate's specialty), failover (Requesty's dashboard-configured chains), and cost_optimize — ready to wire into your Cloudflare Worker as the orchestration backbone.

Groq API Integration:

Extracted central state management efficiently using the robust userReducer pattern to keep the states clean inside src/hooks/useWireframeState.
Search Functionalities:
Added two new responsive real-time search filtering fields:
Quick Search bar inside the generated HTML report phase to filter discovered pages easily.
Quick Search bar within the sidebar of the final built wireframe view section to quickly zoom into specific screens you generate.

Included enhanced error interception and reporting during scraping and LLM generation that properly outputs visually to the application UI.
